# FlowMind AI 工作流平台

参考现代 AI 创作工具设计的可视化工作流平台前端原型。项目为纯 HTML、CSS 与 JavaScript 实现，无需构建即可运行。

## 功能

- 节点库搜索以及点击添加节点
- 可拖拽的工作流节点与节点选中态
- 节点属性配置、重命名和删除
- 画布缩放与缩略图
- 模拟工作流分阶段运行反馈
- 适配桌面、平板和移动端的响应式布局

## 本地运行

```bash
cd ai-video-reverse-prompt-web
python3 -m http.server 8080
```

访问 `http://localhost:8080` 即可体验。

> 当前版本是交互式前端原型。生产环境需接入后端任务编排、模型 API、文件存储、鉴权与持久化能力。
