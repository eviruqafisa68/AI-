# AI镜头反推工作台

一个可直接部署的静态网页 MVP，用于把视频、视频链接、关键帧截图、分镜图和文字说明整理成完整的 AI 视频镜头拆解与提示词反推任务包。

## 当前功能

- 视频、图片、PDF、脚本文件拖拽与选择
- 视频链接与补充说明输入
- 分析重点、平台、生成方式、比例、时长和输出深度配置
- 重点保留项配置
- 自动组合“系统总指令 + 本次分析任务”
- 复制完整任务包
- 导出 TXT
- 系统总指令分章节查看与复制
- 响应式桌面/移动端界面

## 本地运行

这是纯静态项目，可直接双击 `index.html`，或使用任意静态服务器：

```bash
python3 -m http.server 8080
```

然后访问 `http://localhost:8080`。

## GitHub Pages 部署

1. 将全部文件提交到仓库默认分支。
2. 打开仓库 Settings → Pages。
3. Source 选择 `Deploy from a branch`。
4. Branch 选择默认分支，目录选择 `/root`。
5. 保存后等待 GitHub Pages 地址生成。

## 生产版后端建议

当前版本负责前端输入、任务配置和提示词组合，并未在浏览器端调用AI模型。生产版建议增加服务端：

1. 接收视频上传或链接。
2. 使用 FFmpeg 抽帧与提取音频。
3. 使用镜头边界检测建立时间码。
4. 进行语音转写、音乐节拍和声音事件分析。
5. 调用多模态模型进行逐镜头分析。
6. 返回结构化 JSON，由网页渲染为分镜表、提示词卡片和导出文件。

不要在前端代码中直接写入模型 API 密钥。
