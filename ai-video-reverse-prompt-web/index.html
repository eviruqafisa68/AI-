              PRODUCTION PIPELINE
              
从参考视频到AI成片

            

          

          

            
01
素材输入
视频文件、链接、关键帧、分镜图或文字脚本。

            
02
镜头识别
按切镜、动作变化、情绪变化和场景变化建立时间码目录。

            
03
导演拆解
分析景别、机位、运镜、表演、光影、色彩、节奏、转场和声音。

            
04
提示词反推
生成中文、英文、精简版、运镜版、表演版、首尾帧与负面提示词。

            
05
一致性设计
锁定人物、服装、场景、光线、轴线、动作方向和镜头风格。

            
06
生成与后期
按镜头难度选择文生视频、图生视频、首尾帧、后期合成和剪辑。

          

        

      


      

        

          

            

              DEPLOYMENT
              
部署与后端接入

            

          

          

            

              
静态部署

              
当前版本可直接部署到 GitHub Pages、Vercel、Netlify 或任意静态服务器。

            

            

              
AI能力接入

              
生产版建议由服务端接收上传素材，再调用具备视频理解能力的多模态模型。不要把API密钥写在浏览器代码中。

            

            

              
视频链接解析

              
链接解析需要服务端下载、抽帧、音频转写和镜头切分；不同平台还需考虑访问授权与版权边界。

            

            

              
推荐后端流程

              
上传 → FFmpeg抽帧 → 镜头边界检测 → 音频转写 → 多模态分析 → 结构化JSON → 网页渲染与导出。

            

          

          
npm run dev  # 接入框架后本地开发\nGitHub Pages # 当前静态版可直接发布
